Choose where to observe

Use the Hub for network-wide visibility, or an Agent to see which application made a connection on your own computer. Each works on its own; you can combine them later. Only connection metadata is collected, never packet contents.

Whole network

EgressView Hub

Collects from devices behind Yamaha RTX or Cisco IOS routers and combines opt-in Agent observations. TVs and IoT devices are included.

Needs Node.js 22+. Router collection needs a supported router and SSH; Agent-only intake needs no router.

EgressView Agent for Mac

Records this Mac's outbound connections locally with application, destination, and byte count. Hub delivery is optional.

Needs an Apple silicon Mac with macOS 13+. Network monitoring approval is required during setup.

The difference: An Agent sees only its own computer. A router sees devices without installed software, but not the process behind a PC's connection. Opt in to Hub delivery to investigate both together.
