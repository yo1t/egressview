EgressViewAgent

The apps you use —
who are they talking to?

Install EgressView Agent on your Mac or your PC and it records every outbound destination. Metadata only — it never reads what you send. And the record stays yours to keep.

What you get

Which app went where

Country, domain and IP address — and an unfamiliar destination arrives with the program that reached for it, not just an address.

It says what it does not know

Gaps in monitoring are shown as gaps. An empty threat list is never presented as "nothing found" unless something was actually checked.

Nothing is sent to be looked up

Threat lists and locations come to your machine and the matching happens there. No destination of yours is sent anywhere to be identified. What is sent, and where lists every connection the agent makes and every field a Hub receives.

Works on its own

An EgressView Hub adds fleet-wide history and threat feeds, but the agent is useful without one.

Installing

macOS

Apple silicon · macOS 13 or later

  1. Open the .pkg and follow the installer. It places the agent in Applications and starts it.
  2. Choose Network monitoring from the menu bar icon. macOS asks you to approve a System Extension — once.
  3. Updates are offered by the agent itself and install the same way. Approving the System Extension again is not required.

Windows

x64 · Windows 10 or later · no .NET runtime to install first

  1. Run the .msi. Windows asks for administrator approval once: monitoring runs as a Windows service.
  2. The service does the recording and the window is a separate application. Closing the window does not stop the recording.
  3. For now, new versions are downloaded from this page and run by hand. The agent tells you when one exists; it does not install it for you.

Optional: enrolling with a Hub

The same on both

  1. If you run an EgressView Hub, you can enrol this agent with it. The agent works on its own, so you do not need one.
  2. Until you finish enrolling, nothing is sent anywhere. The agent shows the destination and exactly what will and will not be sent, and you confirm you have read it before enrolment can start.

How to verify this app

macOS: signed by Developer ID, notarised by Apple, and stapled.
# the checksum published in the update manifest
curl -s https://dl.egressview.com/macos/manifest.json

# the file you actually downloaded — the two must match
shasum -a 256 ~/Downloads/egressview-agent-VERSION.pkg

# and what macOS itself thinks of it
spctl --assess --type install --verbose=4 ~/Downloads/egressview-agent-VERSION.pkg
Windows: these builds are not yet code-signed. SmartScreen will warn that the publisher is unknown. Check the SHA-256 instead.
# the checksum published in the update manifest
curl.exe -s https://dl.egressview.com/windows/manifest.json

# the file you actually downloaded — the two must match
Get-FileHash -Algorithm SHA256 $HOME\Downloads\EgressView-Agent-Windows-VERSION-x64.msi
