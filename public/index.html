AI洞察

AI機能は初期状態で無効です。接続確認は最小限のリクエストのみを行い（Bedrockは権限確認のため固定の短い文だけを送信します）、通信・端末・脅威データは送信しません。

認証はAWS SDKの標準credential chainに委譲します（キー入力なし）。モデル欄には基盤モデルID、cross-region推論プロファイルID（Global / us. / eu. / apac. / jp.（東京・大阪、日本内処理） / au.）、またはARNを直接入力できます。対応モデルはAWSの提供状況に依存します。

geo を選ぶと、その推論プロファイルのモデルだけを下のモデル欄に表示します。cross-region プロファイル（jp. 等）は on-demand で呼べます。Single-Region は素の基盤モデルで、リージョンによっては呼び出せないことがあります。

⚠ Guardrails は日本内処理を保証しません。日本限定（jp.）の guardrail profile は存在せず、cross-region guardrail は APAC 全域（日本外を含む）へルーティングされ得ます。日本内データレジデンシーが必須の場合は Guardrails をオフにするか、呼び出しリージョン内の single-region guardrail を使ってください。分類フラグ付きの入出力は最大30日保持され得ます。

「接続確認」でモデル一覧を取得すると下のプルダウンから選べます。ARN や未取得モデルは直接入力できます。

APIキーは保存後に再表示されません。生のIP、MAC、端末名、ルーター情報、通信ログはAIへ送信しません。
